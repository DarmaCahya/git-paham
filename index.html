🧰 Modul 3: Kotak P3K Darurat & Tombol Panik

"Salah ketik?", "Salah masukin file rahasia?", "Ada revisi dadakan?". Tenang, ini jurus pembatalannya!

🚨 Kasus Panik #1

Salah Ketik Pesan Commit / Ada File Ketinggalan

Baru saja tekan Enter untuk commit, tapi pesannya typo atau ada 1 script lupa dimasukkan ke kardus. Jangan bikin commit baru lagi!

git commit --amend -m "pesan baru yang benar"
Status: Siap dicoba
🚨 Kasus Panik #2

Salah Masukkan File Rahasia (.env) ke Kardus

Terlanjur git add . dan file .env atau file besar data.parquet ikut masuk kardus Staging Area. Mau dikeluarkan!

git restore --staged .env
Status: Siap dicoba
🚨 Kasus Panik #3

Tugas Mendadak! Meja Masih Berantakan (Laci Meja)

Editanmu belum selesai dan belum bisa di-commit, tapi bos mendadak minta kamu pindah ke branch lain untuk cek bug darurat.

git stash && git stash pop
Status: Meja kotor
🚨 Kasus Panik #4

Kodingan Rusak Total, Mau Balik ke Save-Point

Kamu utak-atik file di meja kerja tapi kodenya malah error parah dan kamu mau buang semua editan hari ini kembali seperti semula.

git restore nama_file.py
Status: Siap dicoba

📖 Modul 4: Kamus Analogi Perintah Modern Git

Bayangkan perintah terminal sebagai aktivitas fisik sehari-hari di kantor.

🔍

git status

Pengecekan Meja
Analogi: Cek Kerapian Meja Kerja

Melihat kondisi berkas di meja: mana kertas yang baru ditulis (merah / untracked), mana yang sudah masuk kardus paket (hijau / staged), dan mana yang belum beres.

git status
📦

git add

Masukkan ke Kardus
Analogi: Memilih File untuk Dikirim

Di meja kerjamu mungkin ada 5 file, tapi kamu hanya mau kirim 2 file yang sudah selesai. Perintah ini memasukkan file pilihanmu ke dalam kotak kardus terbuka (Staging Area).

git add script.py
🏷️

git commit -m

Lakban Kardus & Beri Label
Analogi: Menyegel Save-Point Permanen

Kardus dilakban rapat dan ditempeli stiker catatan jelas, misalnya: "Perbaikan query SQL laporan bulanan". Sekarang berkas ini resmi tersimpan aman di harddisk laptopmu.

git commit -m "feat: pesan"
🚚

git push

Kirim ke Ekspedisi
Analogi: Kirim Paket ke Gudang Pusat

Kardus yang sudah kamu lakban di laptopmu dikirim lewat kurir internet menuju gudang cloud GitHub. Setelah sampai, teman satu timmu bisa melihat dan mengambil hasilnya.

git push origin branch
📥

git pull

Ambil Paket Terbaru
Analogi: Ambil Kiriman Rekan Tim

Sebelum mulai mengetik di pagi hari, ambil dulu kiriman berkas terbaru dari rekan tim di GitHub ke mejamu, agar kamu tidak mengerjakan hal yang sudah dikerjakan orang lain.

git pull origin main
🌿

git switch -c

Meja Kerja Baru (Modern Git)
Analogi: Fotokopi Dokumen ke Meja Sebelah

Di Git modern, perintah checkout diganti dengan git switch -c yang jauh lebih intuitif untuk membuat meja/cabang fitur baru tanpa mengganggu meja utama (main).

git switch -c feat/nama
🔄

git restore

Buang Coretan di Meja
Analogi: Kembalikan Berkas ke Save-Point

Salah ketik atau kodingan rusak? Perintah ini membuang semua coretan ngawur di mejamu dan mengembalikan berkas persis seperti kondisi pada commit terakhir.

git restore file.py
🗄️

git stash

Laci Rahasia Meja
Analogi: Sembunyikan Dokumen Sementara

Simpan dokumen yang belum selesai ke laci meja rahasia agar meja bersih untuk mengerjakan hal darurat lain. Nanti panggil git stash pop untuk mengeluarkannya lagi.

git stash pop
📜

git log --oneline

Buku Ekspedisi Pengiriman
Analogi: Buku Catatan Ekspedisi

Melihat daftar semua kardus commit yang pernah dilakban di masa lalu lengkap dengan hash unik, nama pembuat, dan tanggal pengiriman.

git log --oneline -5

🛡️ Modul 5: Khusus Data Engineers & Keamanan Sistem

Sebagai Data Engineer, ada 6 jebakan umum yang sering bikin repo bengkak dan kredensial bocor.

🚫 1. Jangan Upload File Data Jumbo ke Git!

File seperti dataset.csv (500MB) atau data.parquet (2GB) Haram Masuk Git! Repo akan bengkak dan push gagal.

Solusi Data Engineer: Simpan file jumbo di MinIO / S3 internal / Google Drive. Di repo Git, cukup commit script downloader atau sample data kecil (10 baris pertama).

# Masukkan ini di file .gitignore :
*.csv
*.parquet
*.xlsx
data/
raw_data/

🔐 2. DILARANG KERAS Push Password & API Keys (.env)

Connection string database Postgres/ClickHouse dan API Token LLM TIDAK BOLEH pernah menyentuh GitHub. Sekali ter-push, riwayat Git menyimpannya selamanya!

Aturan Baku: Simpan rahasia di file .env. Buatkan file contoh .env.example (tanpa password asli) untuk tim.

# Wajib ada di .gitignore sejak commit pertama:
.env
.env.local
*.pem
credentials.json

⚠️ 3. Tragedi Jupyter Notebook (.ipynb)

File notebook menyimpan gambar grafik dan riwayat run sel dalam format JSON panjang. Kalau dua orang mengedit notebook yang sama, akan terjadi merge conflict ribuan baris.

# Ritual Sebelum git add file .ipynb:
1. Di menu Jupyter: Pilih Cell -> All Output -> Clear.
2. Simpan notebook yang sudah bersih.
3. Baru lakukan git add file.ipynb.

📝 4. Format Pesan Commit Standar Industri

Hindari pesan malas seperti "update", "fix dikit". Gunakan awalan standar agar mudah dilacak saat pipeline ETL mengalami error.

feat(etl): tambah ekstraksi data arsip setneg
fix(crawler): tangani timeout pada portal berita
refactor(db): optimasi index query agregasi

🕷️ 5. Sampah Script Crawling & Scraping

Script crawler sering men-download ratusan file HTML mentah, cookie login, dan folder cache. Jangan biarkan sampah ini mengotori repo bersama tim.

# Masukkan folder crawler ke .gitignore :
output/
scraped_data/
cookies.json
__pycache__/
.venv/

🖱️ 6. Takut Terminal? Gunakan Menu Source Control Visual!

Kamu tidak harus mengetik hitam-putih di terminal. Di VS Code & Antigravity, ada panel Source Control (Ctrl + Shift + G):

1. Ikon Tambah (+) pada file = sama dengan git add
2. Kotak Pesan + Centang = sama dengan git commit
3. Tombol 'Sync Changes' = sama dengan git push & pull

⚡ Modul 6: Ritual 5 Langkah Harian Standar Proyek

Ritual harian sederhana saat mulai ngoding tugas baru sampai selesai. Centang progresmu di bawah!

Progres: 0/5 Langkah Selesai
1

Pagi Hari (Sync)

git pull origin main

Ambil pembaruan terbaru dari teman satu tim agar mejamu tidak ketinggalan.

2

Bikin Meja Baru

git switch -c feat/task

Buat cabang fotokopi khusus tugasmu hari ini, jangan pernah langsung coret cabang main.

3

Pilih Berkas

git add pipeline.py

Masukkan berkas yang sudah selesai kamu ketik ke dalam kotak kardus paket terbuka.

4

Segel Save Point

git commit -m "..."

Lakban kardus dan beri catatan singkat apa fungsi kode yang baru selesai dibuat.

5

Kirim ke Tim

git push origin feat/task

Kirim ke GitHub, lalu klik tombol 'Create Pull Request' di web browser untuk dicek rekan.
